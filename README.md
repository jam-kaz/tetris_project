## Описание проекта
Программа представляет собой графическую реализацию классической игры «Тетрис» на языке Python. Игрок управляет падающими разноцветными фигурами, поворачивая и перемещая их для заполнения горизонтальных рядов и набора очков.

## Функциональные возможности
### Основной функционал
- Генерация 7 классических цветных фигур тетрамино
- Перемещение фигур влево, вправо и ускорение падения вниз
- Поворот фигур на 90 градусов с проверкой коллизий
- Автоматическое удаление заполненных линий и подсчет очков

### Дополнительный функционал
- Пауза и возобновление игры (пробел)
- Мгновенный перезапуск после окончания игры (R)

## Требования к системе
- **Python:** 3.9 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:** встроенная графическая библиотека `tkinter`, модуль `random`, `typing`

## Установка и запуск
### 1. Клонирование репозитория
```bash
git clone https://github.com/jam-kaz/tetris_project.git
cd tetris_project
```

### 2. Создание и активация виртуального окружения
**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
```bash
python main.py
```

### 5. Управление в игре
- `←` / `→` — сдвиг фигуры влево / вправо
- `↓` — ускорить падение фигуры
- `↑` — повернуть фигуру на 90°
- `Space` — пауза / продолжить
- `R` — перезапуск игры

## Структура проекта
```text
tetris_project/
├── .gitignore
├── README.md
├── requirements.txt
├── main.py
└── src/
    ├── __init__.py
    ├── app.py
    ├── models/
    │   ├── __init__.py
    │   └── tetris_model.py
    └── renderers/
        ├── __init__.py
        └── renderer.py
```

**Назначение основных модулей:**
- `main.py` — точка входа в программу
- `src/app.py` — класс `TetrisApp`, управление окном, таймером и нажатиями клавиш
- `src/models/tetris_model.py` — класс `TetrisModel`, игровая сетка, математика поворотов и проверка столкновений
- `src/renderers/renderer.py` — класс `TetrisRenderer`, отрисовка сетки, фигур и экранов состояния на холсте

## Пример использования
После запуска `python main.py` открывается игровое окно размером 10×20 клеток. Фигуры начинают падать сверху; при заполнении горизонтального ряда линия исчезает, а счетчик в верхней части окна увеличивается на 100 очков.
